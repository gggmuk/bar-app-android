# 🍺 Bar App Android

Мобильное приложение для управления баром на Android.

## 📱 О проекте

Android-приложение для управления баром с использованием современных технологий разработки.

## 🔧 Технологии

- **Язык:** Java / Kotlin
- **Система сборки:** Gradle 8.2.0
- **Android SDK:** 8.2.0
- **Архитектура:** MVP/MVVM

## 📦 Структура проекта

```
android_project1/
├── app/                    # Модуль приложения
│   ├── src/
│   │   └── main/
│   │       ├── java/       # Исходный код
│   │       ├── res/        # Ресурсы
│   │       └── AndroidManifest.xml
│   └── build.gradle        # Зависимости модуля
├── gradle/                 # Wrapper Gradle
├── build.gradle            # Корневой конфиг
└── settings.gradle         # Настройки проекта
```

## 🚀 Запуск проекта

### Предварительные требования
- Android Studio
- JDK 17+
- Android SDK

### Установка
```bash
git clone https://github.com/gggmuk/bar-app-android.git
cd bar-app-android
```

### Сборка
```bash
./gradlew assembleDebug
```
